## 🔄 Conceitos de CRUD

CRUD representa as quatro operações fundamentais utilizadas para gerenciar dados em uma aplicação.

| Operação | Método HTTP | Finalidade |
|---|---|---|
| Create | POST | Criar novos registros |
| Read | GET | Consultar registros |
| Update | PUT / PATCH | Atualizar registros |
| Delete | DELETE | Excluir registros |

Essas operações são fundamentais no desenvolvimento de APIs e aplicações que utilizam bancos de dados.
